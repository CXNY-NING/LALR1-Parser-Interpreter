# 四元式解释器需求报告

## 1. 项目目标

为现有 LALR(1) 编译器生成的四元式序列（`quads.txt`）提供一个独立的 C 语言解释执行器，用于验证中间代码的正确性。

本解释器与主编译器项目完全隔离，单独存放于 `QuadInterpreter/` 文件夹中。

## 2. 输入格式

直接读取现有 `quads.txt` 的格式：

```
index : (op, arg1, arg2, result)
```

例如：

```
0   : (goto, -     , -     , 11)
1   : (proc, s     , -     , -)
2   : (/   , n     , k     , t0)
```

解析规则：

- 忽略行首的 `index` 序号，按文件中的顺序生成四元式序列；
- 四元式内部字段用逗号 `,` 分隔；
- 空字段用 `-` 表示；
- 忽略多余空白。

## 3. 数据模型

- 仅支持 `int` 类型；
- 变量无需预先声明，首次被赋值时自动创建；
- 变量名包括源程序标识符和编译器生成的临时变量（如 `t0`、`t1` 等）；
- 所有变量视为全局变量，过程之间通过全局变量通信。

## 4. 支持的操作码

### 4.1 算术运算

| 操作码 | 含义 | 四元式形式 | 语义 |
|--------|------|-----------|------|
| `+` | 加法 | `(+, a, b, t)` | `t = a + b` |
| `-` | 减法 | `(-, a, b, t)` | `t = a - b` |
| `*` | 乘法 | `(*, a, b, t)` | `t = a * b` |
| `/` | 整除 | `(/, a, b, t)` | `t = a / b` |

### 4.2 赋值

| 操作码 | 含义 | 四元式形式 | 语义 |
|--------|------|-----------|------|
| `:=` | 赋值 | `(:=, src, -, dst)` | `dst = src` |

### 4.3 跳转

| 操作码 | 含义 | 四元式形式 | 语义 |
|--------|------|-----------|------|
| `goto` | 无条件跳转 | `(goto, -, -, L)` | `PC = L` |
| `j=` | 相等则跳转 | `(j=, a, b, L)` | 若 `a == b`，则 `PC = L` |
| `j<>` | 不等则跳转 | `(j<>, a, b, L)` | 若 `a != b`，则 `PC = L` |
| `j<` | 小于则跳转 | `(j<, a, b, L)` | 若 `a < b`，则 `PC = L` |
| `j>` | 大于则跳转 | `(j>, a, b, L)` | 若 `a > b`，则 `PC = L` |
| `j<=` | 小于等于则跳转 | `(j<=, a, b, L)` | 若 `a <= b`，则 `PC = L` |
| `j>=` | 大于等于则跳转 | `(j>=, a, b, L)` | 若 `a >= b`，则 `PC = L` |
| `jodd` | 奇数则跳转 | `(jodd, a, -, L)` | 若 `a` 为奇数，则 `PC = L` |

### 4.4 过程调用

| 操作码 | 含义 | 四元式形式 | 语义 |
|--------|------|-----------|------|
| `proc` | 过程入口 | `(proc, name, -, -)` | 标记过程 `name` 的开始 |
| `endproc` | 过程出口 | `(endproc, -, -, -)` | 返回到调用者的下一条四元式 |
| `call` | 调用过程 | `(call, name, -, -)` | 保存返回地址，跳转到 `name` 对应的过程入口 |

### 4.5 调试输出

| 操作码 | 含义 | 四元式形式 | 语义 |
|--------|------|-----------|------|
| `print` | 打印变量值 | `(print, x, -, -)` | 输出 `x = 值` |

## 5. 执行模型

- 维护一个程序计数器 `PC`，初始为 0；
- 顺序执行四元式，遇到跳转则修改 `PC`；
- 过程调用使用调用栈保存返回地址；
- PL/0 风格：过程无参数、无返回值，通过全局变量通信。

## 6. 用户交互

程序启动时，依次询问用户：

1. **是否开启追踪模式？**（yes/no）
   - 追踪模式下，每执行一条四元式打印一条执行信息。
2. **是否开启单步模式？**（yes/no）
   - 单步模式下，每执行一条四元式后暂停，等待用户按回车继续。

结束模式始终开启：程序执行完毕后，自动打印所有变量及其最终值。

## 7. 错误处理

遇到以下情况时，打印错误信息并退出：

- 除以零；
- 读取未定义的变量；
- 遇到不认识的四元式操作码；
- 跳转目标不存在；
- 调用不存在的过程。

## 8. 输出格式

### 8.1 追踪模式输出

```
[PC=2] / n k -> t0   (t0 = 4)
```

### 8.2 过程调用追踪

```
--> call s, return to 11
<-- endproc s, return to 11
```

### 8.3 结束输出

```
最终变量值:
  m = 15
  n = 35
  t0 = 4
  ...
```

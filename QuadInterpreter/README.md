# 四元式解释器使用说明

## 编译

使用 Visual C++ 编译器：

```bash
cl main.c
```

或使用 GCC：

```bash
gcc main.c -o quad_interp.exe
```

## 运行

默认读取当前目录下的 `quads.txt`：

```bash
quad_interp.exe
```

也可以指定其他四元式文件：

```bash
quad_interp.exe my_quads.txt
```

## 交互选项

程序启动后会依次询问：

1. **是否开启追踪模式**：每执行一条四元式就打印详细信息。
2. **是否开启单步模式**：每执行一条四元式后暂停，按回车继续。

无论是否开启上述模式，程序结束时都会打印所有变量的最终值。

## 支持的测试

当前目录下的 `quads.txt` 来自主 LALR(1) 编译器。注意：该测试文件的主程序部分为空（只有过程声明，没有顶层调用语句），因此解释器会直接结束。若要观察过程调用和计算过程，请使用包含 `call` 语句的四元式文件。
